# 扩大有效样本和构造多样性

上一批 9,216 条音频只来自 96 个原始音色和一个固定结构。很多条目只是同一实例的音高、时序或增益变体，不能把文件数等同于独立音色数量。这次优先扩大原始构造空间，再覆盖演奏变化。

## 规模和独立性

32 个原生 DSP 结构族，每族 512 个以 Latin hypercube 分层采样的原始构造，共 16,384 个 C。每个 C 配对一个明确受边界约束的多坐标扰动 I，两者各自覆盖四种演奏或输入条件，共 131,072 个 datapoint。所有原始目标在生成变体之前确定。

不靠复制 WAV、随机增益或重命名目标扩大数量。除数值参数外，构造标签保留原生运算身份、参数切片、时钟、状态容量、初始化、不可变 assets、音频操作数绑定、路由、调制及实际可听输出混音。FIR 的系数监督也包含在 asset 目标中。稀疏空槽是 padding，分配过的数值零是 present，两者分别编码。

独立性检查分为：完整 C 内容身份不重复；输出 WAV 内容指纹；相对特征的粗量化指纹；以及统一演奏/统一激励条件下各 C 的原生响应。最后一项删除绝对音量和持续时间，避免这些差异抬高音色多样性计数。以上是构造与声学多样性诊断，不是统计 effective sample size 或感知独立性的证明。

## 32 个结构族

| 范围 | 构造 |
|---|---|
| 加法与非整数泛音 | 4/12 部分音、8 个非整数部分音；独立谱斜率和相对幅度 |
| 减法合成 | saw→低通/带通/高通，包络驱动滤波频率；低通→tanh 与 tanh→低通分别保留 |
| 波表 | 已知固定波表→低通，频率/滤波/包络/声像变化 |
| 频率与幅度调制 | 环形调制、FM、AM、FM→低通；原生输出历史驱动调制 |
| 时变与循环 | 调制分数延迟加干声、phaser、环形 allpass/comb、递归 tanh |
| 噪声和物理 | 噪声→带通/模态；冲激→4/12 模态；冲激→调谐波导；加法→共振器 |
| 非线性 | cubic softclip、tanh 和递归反馈，保留操作顺序及其差异 |
| 成对 FX | 低通/高通/带通、tanh、phaser、立体声宽度、反馈分数延迟、可变 FIR |

每个结构族的操作和坐标语义由 `coordinate-semantics.json` 与 `operation-vocabulary.json` 记录。32 个结构族是覆盖课程，不宣称枚举任意 DSP 图或涵盖所有仓库运算。初始噪声种子和波表等条件明确已知；不把它们冒充未知真实录音的唯一原始构造。

## 演奏、激励、时间和声道

四个受控条件跨越 MIDI 寄存器、力度、细调、松键时间、staccato、再次触发和 vibrato。采样率覆盖 16/24 kHz，音频使用立体声 PCM24。音频时长按构造及条件变化；物理/模态样本保留更长观察窗口。高频配置受 Nyquist 和原生内核范围约束。

FX 保存真正送入 DSP 的输入音频与输出音频。激励包括双音、宽带 chirp、噪声 burst、和弦，左右声道有不同相位和成分。输入先量化到保存的 PCM24，再送入原生渲染器，确保输入文件能够精确重放。每个原始配置的 identity/I 复用同一输入，构成有监督的反事实对；不混淆输入变化和 FX 参数变化。

ADSR、调制、递归及输出增益真正运行于原生图中。只按文档 `outputMix` 导出可听输出，不把内部包络/相位/状态通道提供给识别模型。录音是已知的受控条件，没有伪造房间校准、真实用户偏好、重要性排序或通用去噪标签。

## 数据表示和训练使用

每个分片的 `prepared.npz` 含：

- `X_audio`：输出和条件输入的宽带特征，各包含 32 个有序时间窗、32 个绝对对数频率点、两个声道相对 RMS、声道关系、时长和整体 RMS。噪声/FX 不需要虚构一个基频。频谱归一化使用完整 clip 的 RMS，避免静音窗的局部最大值放大量化噪声。
- `conditions`：采样率、时长、力度、时序、音高/调音、vibrato 等已知性能条件。和音频特征分开存储，供条件训练或缺失条件策略选择。
- `canonical_*` / `instance_*`：activation、parameters、routing、modulation、assets 及各自 mask。
- 两头的 `node_ops`、`node_layout`、`edges` 和 mask：运算 token、参数切片、状态/时钟/输入/资产布局、带来源和延迟语义的绑定。
- `id`、`canonical_id`、`split`、`type_id`、`fx_input_mask`：索引/监督/任务上下文。构造族 ID 是元数据或预测目标，不能作为未知 WAV 的隐含答案拼入 encoder 输入。

原始完整 C/I JSON 是最终构造真值，保留 compact tensor pack 未展开的所有细节，包括初始状态和输出混音。不能仅把不同操作的扁平参数下标拼成同一语义的回归坐标。下一轮联合模型应以原生运算和图布局解释参数字段；已知模板任务可以在单个结构族内回归张量。

`ShardReader.batches()` 每次只加载一个有限分片。分片为 64 个原始配置/512 条样本；避免逐 item 重复解压整个数据集。数据生成与验证均在 CPU 进行，不启动 optimizer。

现有 `training.amo` WAV learner 不预测未知拓扑，也不读取 FX 的条件输入。为它提供经过明确语音/基频适用性筛选、结构和坐标一致的 `*-legacy-manifest.json`，并运行真实预检/特征提取。全量噪声、物理、调制和 FX/图监督由宽带分片接口读取，不把它们强行套进参考谐波特征。全量 corpus 的准备完成不等于旧 learner 已获得通用结构识别能力。

## 分区和验证

默认各结构族按完整原始构造分为 75% train、12.5% validation、12.5% test。任何 C 的 I/演奏/采样率变体均随同 C，测试数据不进入 reference learner manifest。

另提供 `unseen-topology-protocol.json`，完全留出 saw→LP→tanh、FM→LP、FX phaser、FX ring-delay 四类组合，相关操作在其余结构中已出现。普通划分考察未见参数配置，组合划分考察未见模块组合；在拟合之前选择一个协议，不能普通训练后再宣称这些组合是未见结构。

质量核验包括原生编译/实际渲染、有限值、峰值/低能量检查、可重复 reset、全部音频和标签内容指纹、无分区泄漏、mask/图/资产目标和完整 JSON 一致，以及从每个分片的多个分区/扰动重放并重新计算特征。PCM24 重放误差按量化精度验证。观察窗口结束的尾部 RMS 保留在质量记录，不把持续声或尚未完全衰减的状态人为静音。

统一条件的额外 diversity audit 用同一激励比较 512 个原始配置，删除音量/时长，只报告实际的响应区分度和邻近距离；不使用测试集调模型或选择参数。
