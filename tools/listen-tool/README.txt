AMO 试听工具（结构编码器 · 第三轮）
=====================================

它能做什么
----------
给它一段声音，模型会猜出这段声音是用我们哪一种合成结构、哪些参数做出来的，
再用我们自己的 DSP 把猜出来的结构重新演奏一遍。你可以对比原声和重渲染，
听模型猜得像不像。猜出的结构会保存成可编辑的 construction.json。

怎么用（Windows 10/11，需要联网安装一次）
-----------------------------------------
1. 双击 1-install.bat。它会在这个文件夹里装一个独立的 Python 和 PyTorch，
   约 1 GB，不会动系统里的任何东西。装完窗口会显示 Done。
2. 双击 2-demo.bat。它会随机生成 8 个我们自己结构的声音，让模型逐个去猜，
   结果在 results\demo 里，每个声音一个文件夹：
     original.wav   模型听到的原声
     resynth.wav    用模型猜出的结构重新渲染的结果
     guess.json     猜的是哪种结构（前三名和概率）以及频谱距离
   频谱距离越小越像：test 集中位数约 0.18，完全不懂时（族平均）约 0.51。
3. 想试自己的声音：把一个或多个 WAV 文件拖到 3-resynth-my-wav.bat 上。
   结果在 results\my-wav 里。

要知道的限制
------------
- 模型只听过我们自己 24 种乐器结构合成的声音（加法、减法滤波、波表、FM/AM/环形调制、
  chorus/phaser/comb、噪声、模态、波导等）。真实乐器录音、人声、整段音乐都超出了
  它学过的范围，结果只会是这些结构能做出的最接近的声音，不会是原声的复制。
- 最适合：单个音符、按住约 1–2 秒、音高在 A#1 到 A4（MIDI 34–69）之间的合成音色。
  超过 2.4 秒的部分会被截掉。音高会自动估计，估错时结果会明显不像。
- 运行时只用 2 个 CPU 线程、低优先级，风扇不会狂转，但每个声音要几秒钟。

卸载：直接删除整个文件夹。

本工具仅供私下试用。插件框架 JUCE 目前按 AGPLv3 使用；训练数据全部由
Alfamedomega 自己的 DSP 生成，不含第三方插件或录音。
